# 점프! 로봇 🤖

한 손가락으로 하는 점프 게임입니다.

**게임 주소** → `https://logos113.github.io/Project-begins/game/`

---

## 🎮 게임하는 법

| 조작 | 하는 일 |
|---|---|
| 화면을 톡 | 점프 |
| **◀ ▶** 버튼 (왼쪽 아래) | 걷기 — **거인과 싸울 때만** 나옵니다 |
| 공중에서 한 번 더 톡 | **두 번 점프** (더 높이! 높이 뜬 아이템은 이걸로만 닿아요) |
| **발사** 버튼 | 무기 쏘기 (보스와 싸울 때만 나타나요) |
| 성 앞에서 **카드 누르기** | 마법사에게 무기 받기 |
| **멈춤** 버튼 (오른쪽 위) | 하던 판을 멈추기 |

### 게임 중에 그만두고 싶으면

오른쪽 위 **멈춤** 을 누르세요. 그 자리에서 멈추고 세 갈래가 나옵니다.

- **이어서 하기** — 멈춘 그 자리에서 계속
- **그만두기** — 이번 판을 끝내고 점수 확인
- **← Dr. Y's Archive** — 다른 앱으로

컴퓨터에서는 `Esc` 나 `P` 키로도 멈추고 이어서 할 수 있어요.

- 화면 위에 **♥ 가 세 칸** 있어요. **세 번 맞으면** 끝납니다
- 맞은 직후에는 잠깐 **깜빡이는데, 그동안은 안 맞아요**
- 노란 코인을 먹으면 **10점** 보너스
- 떠 있는 **아이템 🔷 ⭐ 💗** 을 먹으면 잠깐 세지거나 체력이 돌아와요
- 보스로 가는 길 한가운데에 **성**이 있어요. 마법사가 무기를 줍니다
- **300점마다 보스**가 찾아옵니다 (따로 준비할 건 없어요)
- 속도는 **스테이지 안에서 계속 같아요.** 보스를 이겨야 다음 스테이지로
  넘어가면서 조금 빨라집니다

휴대폰을 **가로로 눕히면** 앞이 더 잘 보여서 유리해요.

## 🎁 아이템 세 가지

달리다 보면 공중에 아이템이 떠 있습니다. **모아두는 것이 아니라,
먹는 즉시 효과가 생기는 것**입니다. 세 가지가 무작위로 나와요.

| 모양 | 이름 | 하는 일 | 얼마나 자주 |
|---|---|---|---|
| 🔷 하늘색 마름모 | **강화** | 미사일이 **두 배로 세지고 더 빨리** 나갑니다 (보스전 10초) | 약 44% |
| ⭐ 노란 별 | **무적** | 5초 동안 **아무것도 맞지 않습니다** | 약 22% |
| 💗 분홍 하트 | **회복** | ♥ 를 한 칸 채웁니다 (가득이면 대신 **50점**) | 약 33% |

지금 걸려 있는 효과는 화면 위 둘째 줄에
`🔱 흩어쏘기  🔷 강화 10초 보관  ⭐ 무적 5초` 처럼 보입니다.

### 🔷 강화는 보스전까지 품고 갑니다

미사일은 **보스와 싸울 때만** 쏠 수 있어요. 그래서 강화 시간은
**보스를 만나야 흐르기 시작합니다.**

길에서 🔷 를 먹으면 `🔷 강화 10초 보관` 이라고 뜨고, 숫자가 줄지 않은 채
그대로 기다립니다. 보스와 싸움이 시작되면 그때부터 10초가 흘러가요.

> **고쳤던 일** — 처음에는 먹는 순간부터 시간이 흘렀습니다. 그런데 🔷 는
> 달리는 길에 뜨고 보스는 한참 뒤에 오니까, **보스가 오기도 전에 10초가
> 다 녹아** 한 번도 써보지 못했습니다. 세 아이템 중에 혼자만 쓸모가
> 없었던 셈입니다.

### 높이 뜬 아이템 — 두 번 점프로만 닿아요

아이템 중 **셋에 하나쯤은 아주 높이** 떠 있고, 그 아래에 **점선**이 그어져
있습니다. 점선이 보이면 *"한 번 점프로는 못 닿는다"* 는 표시예요.
뛰어오른 **다음에 공중에서 한 번 더** 눌러야 닿습니다.

> 한 번 점프로 닿는 높이는 화면 기준 81 정도인데, 높이 뜬 아이템은 40~62 에
> 있습니다. 두 번 점프를 하면 -29 까지 올라가니 넉넉히 닿습니다.

## 🏰 성과 마법사 — 무기 업그레이드

달리다 보면 저 앞에 **성**이 보입니다. 로봇이 성 앞에 멈춰 서면
**마법사**가 나와서 무기 세 가지를 보여줘요. 하나를 고르면 그 무기로 바뀝니다.

**고르는 동안에는 게임이 완전히 멈춥니다.** 점수도 안 오르고 장애물도
다가오지 않아요. 천천히 읽어보고 고르면 됩니다.

### 무기 다섯 가지

| | 이름 | 하는 일 | 초당 위력 |
|---|---|---|---|
| 🚀 | **기본 미사일** | 처음부터 가지고 있는 무기 | 1.5 |
| 💣 | **폭탄** | 한 방이 아주 셉니다. 대신 느리게 날아가요 | 2.7 |
| ⚡ | **연발 미사일** | 빠르게 누르는 만큼 쉴 새 없이 나갑니다 | 3.8 |
| 🔆 | **레이저** | 눈 깜짝할 새에 날아가 맞힙니다 | 3.5 |
| 🔱 | **흩어쏘기** | 한 번에 세 발이 부챗살처럼 퍼집니다 | 3.1 |
| 🗡️ | **칼** | 거인 앞까지 다가가서 벱니다 | 4.5 |

마법사는 **기본 미사일은 주지 않아요.** 다른 것들보다 약해서, 골라야 할
이유가 없는 칸 하나를 버리는 셈이 되거든요.

> 초당 위력은 짐작이 아니라 **체력 12짜리 거인을 잡는 데 걸린 시간을
> 실제로 재서** 적은 값입니다.

### 🗡️ 칼은 좀 다릅니다

칼은 **날아가지 않습니다.** 로봇 코앞을 베기 때문에, ◀ ▶ 로
**거인 바로 앞까지 걸어가야** 닿아요.

가장 세지만(초당 4.5) 다가가는 데 2초쯤 걸리고, 거인 코앞에 서 있으니
돌에 맞기도 제일 쉽습니다. **한 번 맞으면 칼을 잃습니다.**
세고 위험한 무기예요.

### ⚠️ 한 번만 다쳐도 무기를 잃어요

이게 이 게임의 새 규칙입니다.

> **체력이 한 칸이라도 줄면 기본 미사일로 돌아갑니다.**
> 장애물에 닿든, 보스탄에 맞든 똑같아요.

그래서 좋은 무기를 받고 나면 저절로 조심하게 됩니다.
평소에는 아슬아슬하게 지나가던 장애물도 크게 돌아가게 돼요.

깜빡이는 동안(맞은 직후 무적)에는 안 맞는 것으로 치니까 무기도 지킵니다.
⭐ **무적** 아이템을 먹어두면 그동안은 무기를 잃을 걱정이 없어요.

지금 들고 있는 무기는 화면 위에 `💣 폭탄` 처럼 보입니다.
기본 미사일일 때는 아무것도 안 보여요.

### 성은 언제 오나

**보스와 보스 사이 한가운데**입니다. 게임은 이렇게 흘러갑니다.

```
장애물 구간 → 🏰 성(무기 받기) → 장애물 구간 → 👾 보스
            → 장애물 구간 → 🏰 성 → 장애물 구간 → 👾 보스 → ...
```

첫 성은 **150점**, 첫 보스는 **300점**입니다.
보스를 잡으면 그 자리에서 다시 150점 뒤에 성, 300점 뒤에 보스가 옵니다.

## 👾 보스와 싸우기

**300점을 넘기면** 커다란 **거인**이 쿵쿵 걸어옵니다.
그다음부터는 **보스를 잡은 자리에서 300점을 더 달리면** 다음 보스가 옵니다.
미리 모아둘 것도, 준비할 것도 없어요. 달리다 보면 반드시 만납니다.

게임은 이렇게 번갈아 갑니다.

```
장애물 구간 → 1단계 보스 → 장애물 구간(조금 빠르게) → 2단계 보스
            → 장애물 구간(더 빠르게) → 3단계 보스 → ...
```

보스를 잡으면 화면에 **다음 보스가 몇 점인지** 알려줍니다.

### 거인을 만나면 멈춰 섭니다

거인이 앞을 막아서면 **달리기가 멈춥니다.** 배경도 점수도 그대로 멈춰요.
그 대신 **왼쪽 아래 ◀ ▶ 버튼으로 걸어 다닐 수 있습니다.**

```
달릴 때   세상이 흘러가고 로봇은 제자리     (점프만)
싸울 때   세상이 멈추고 로봇이 걸어 다님   (점프 + 걷기 + 발사)
```

가까이 가면 🗡️ 칼이 닿고, 멀리 떨어지면 돌을 피하기 쉬워요.
어디에 설지는 들고 있는 무기에 따라 정하면 됩니다.

싸우는 동안에는 **장애물이 나오지 않아요.** 거인만 신경 쓰면 됩니다.
(싸움이 시작될 때 화면에 남아 있던 장애물은 치웁니다. 세상이 멈추니까
그대로 두면 한복판에 얼어붙은 채 남거든요.)

컴퓨터에서는 **← → 키**나 **A · D 키**로도 걸을 수 있어요.

> 예전에는 파란 아이템을 4개 모아야 보스가 나왔습니다. 그런데 그러면
> **아이템을 안 먹는 쪽이 더 편한** 게임이 되어 버립니다. 보스를 피하면
> 속도도 안 오르고 위험할 일도 없으니까요. 지금은 보스가 반드시 오고,
> 아이템은 그 싸움을 쉽게 해주는 쪽으로 바뀌었습니다.

### 어떻게 이기나

오른쪽 아래 **발사** 버튼을 누르면 미사일이 나갑니다.
미사일은 보스를 따라가니까 겨냥하지 않아도 돼요.
스테이지 1 보스는 **네 번 맞히면** 쓰러집니다.

**미사일은 얼마든지 쏠 수 있습니다.** 대신 한 발 쏘면 다음 발까지
**채우는 시간**이 있어요. 채우는 동안에는 발사 버튼이 흐려집니다.
기본 미사일은 0.7초, 마법사에게 받은 무기는 더 짧거나 더 셉니다.
🔷 **강화**를 먹어두면 채우는 시간이 절반쯤으로 줄고 위력이 두 배가 됩니다.

이기면 **200점**을 받고 다음 스테이지로 넘어갑니다.
보스는 화면 밖으로 날아 나가고, 잠시 뒤 장애물이 다시 나오기 시작해요.

> **고쳤던 일** — 처음에는 1단계를 깨고 나면 **보스만 계속 나왔습니다.**
> 보스가 나올 때 문턱에 300을 더하는 방식이었는데, 격파 보상은 스테이지마다
> 100점씩 커집니다. 그래서 900점에서 3보스를 잡으면 +400 으로 1300점이 되어
> 다음 문턱(1200점)을 이미 넘어버렸습니다. 지금은 **보상을 받은 뒤의
> 점수에서** 다시 세기 때문에, 보상이 아무리 커져도 사이에 달리는 구간이
> 반드시 들어갑니다.

### 스테이지가 오를수록 보스가 세집니다

| 스테이지 | 달리는 속도 | 보스 체력 | 쏘는 간격 | 보상 |
|---|---|---|---|---|
| 1 | 4.0 | 4 | 95 | 200점 |
| 2 | 4.5 | 5 | 87 | 300점 |
| 3 | 5.0 | 6 | 79 | 400점 |
| 4 | 5.5 | 7 | 71 | 500점 |
| 5 | 6.0 | 8 | 63 | 600점 |
| 6 | 6.5 | 9 | 55 | 700점 |

쏘는 간격은 작을수록 자주 쏜다는 뜻이고, 날아오는 속도도 함께 빨라집니다.
체력·속도·간격에는 **상한**이 있어서 어느 선에서 멈춥니다.
없으면 열 스테이지쯤 가서 도저히 이길 수 없는 게임이 됩니다.

**모습도 달라집니다.**

| | 스테이지 1 | 3 | 5 이상 |
|---|---|---|---|
| 키 | 146 | 172 | 198 이상 |
| 색 | 보라 | 청록 | 빨강 · 금색 |
| 뿔 | 2개 | 4개 | 6개 이상 |
| 눈 | 1개 | 2개 | 3개 |
| 빛무리 | 없음 | 있음 | 있음 |

색은 여섯 가지가 차례로 돌아갑니다 — 보라 · 파랑 · 청록 · 주황 · 빨강 · 금색.

### 스테이지 — 속도가 올라가는 유일한 순간

**보스를 이길 때만** 스테이지가 1 올라가고, 그때 조금 빨라집니다.
한 스테이지 안에서는 처음부터 끝까지 **같은 속도**로 달려요.

보스를 만나기만 해서는 오르지 않습니다. **이겨야** 오릅니다.
빨라지는 것도, 200점 보너스도, 이겨야 받습니다.

> 예전에는 시간이 흐를수록 계속 빨라졌는데, **20초면 최고 속도**에 닿을 만큼
> 가팔랐습니다. 지금은 내가 이긴 만큼만 빨라집니다.

### 어떻게 피하나

거인이 던지는 붉은 돌은 **두 가지**입니다.

| | 해야 할 것 |
|---|---|
| 발밑으로 낮게 | **점프**해서 넘기 |
| 머리 위로 높게 | **가만히 서 있기** (뛰면 맞아요!) |

**던지기 전에 거인이 손으로 알려줍니다.**

```
손을 내리면  →  낮게 온다   →  점프 준비
손을 올리면  →  높게 온다   →  가만히 서 있기
```

손이 번쩍이는 동안(약 0.5초)이 피할 준비를 할 시간이에요.

> **왜 예고를 넣었나** — 로봇이 거인 코앞까지 걸어갈 수 있게 되면서,
> 가까이 붙으면 돌이 **서너 장면 만에** 닿게 되었습니다. 날아오는 길을
> 보고 판단할 틈이 아예 없었어요. 그래서 던지기 전에 손을 먼저
> 움직이게 했습니다.

맞으면 ♥ 가 한 칸 줄어듭니다. 세 칸을 다 잃으면 끝나요.
보스는 물러가지 않습니다. **쓰러뜨리거나, 내가 쓰러지거나** 둘 중 하나예요.
⭐ **무적**을 아껴 두었다가 보스전에서 먹으면 5초를 마음껏 쏠 수 있습니다.

### 보스가 너무 어렵거나 쉬우면

`game.js` 맨 위에서 숫자를 바꿔보세요.

```js
로봇_체력: 3,           // 1 로 하면 예전처럼 한 방에 끝나요
무적_시간: 75,          // 맞은 뒤 깜빡이는 길이 (60 이 1초쯤)

보스_나오는점수: 300,   // 보스 사이에 달리는 거리. 150 이면 두 배로 자주 만나요
옆걸음_속도: 4.5,      // 싸울 때 걷는 빠르기 (8 로 하면 쌩쌩 달려요)
보스_준비시간: 28,     // 던지기 전 예고 길이. 60 으로 하면 아주 쉬워져요
보스_기본체력: 4,       // 스테이지 1 보스의 체력 (3 으로 하면 쉬워져요)
보스_체력_증가: 1,      // 0 으로 하면 보스가 세지지 않아요
보스_최대체력: 10,      // 아무리 세져도 여기까지
보스_공격간격: 95,      // 200 으로 하면 훨씬 덜 쏴요 (쉬워짐)
보스_공격간격_감소: 8,  // 0 으로 하면 스테이지가 올라도 같은 간격
보스탄_속도_증가: 0.45, // 0 으로 하면 쏘는 속도가 그대로
성_나오는_비율: 0.5,    // 0.25 로 하면 성이 더 일찍 나와요
고를_무기_개수: 3,      // 마법사가 한 번에 보여주는 가짓수
```

무기의 숫자는 `무기들:` 안에 무기마다 따로 적혀 있습니다.

```js
폭탄: { 위력: 4, 재장전: 90, 속도: 6.5, 유도: 0.10, 발수: 1, 퍼짐: 0, ... },
//       ↑ 한 발이 깎는 체력   ↑ 다음 발까지 (60 이 1초. 작을수록 자주)
```

새 무기를 만들고 싶으면 이 표에 한 줄 더 넣으면 됩니다.
`발수` 를 5, `퍼짐` 을 0.3 으로 하면 다섯 발이 확 퍼지는 무기가 돼요.

> **보스를 계속 같은 세기로 두려면** `보스_체력_증가` · `보스_공격간격_감소` ·
> `보스탄_속도_증가` 를 전부 `0` 으로 두면 됩니다. 속도만 스테이지마다 오릅니다.

> **무적_시간은 0 으로 두지 마세요.** 장애물에 부딪히면 몸이 겹쳐 있는 동안
> 세 칸이 순식간에 다 사라집니다. 체력이 있으나 마나 해집니다.

> **미사일_유도 이야기** — 처음에는 미사일이 똑바로만 날아가게 만들었는데,
> 보스가 위아래로 떠다녀서 **명중률이 33%** 밖에 안 됐습니다.
> 실제로 재보고 나서 살짝 따라가게 고쳤더니 100%가 되었습니다.
> 겨냥하는 재미를 원하면 `0` 으로 두세요. 대신 채우는 동안에도 보스는
> 계속 쏘기 때문에 훨씬 어려워집니다.

## 🛠 게임을 내 맘대로 바꿔보기

`game.js` 파일을 열면 **맨 위에 숫자들이 모여** 있어요.
숫자를 바꾸고 저장한 다음, 게임 화면을 새로고침하면 바로 달라집니다.

**망가뜨릴 걱정은 하지 마세요.** 이상해지면 원래 숫자로 되돌리면 됩니다.

### 이걸 먼저 해보세요 (재미있는 순서대로)

**① 달나라 점프**
```js
중력: 0.55,   →   중력: 0.15,
```
아주 천천히 떠올랐다가 사르르 내려와요. 우주에 온 것 같아요.

**② 슈퍼 점프**
```js
점프_힘: 11,   →   점프_힘: 22,
```
화면 밖까지 날아갑니다. 장애물이 하나도 안 보여요!

**③ 초고속 모드**
```js
시작_속도: 4.0,   →   시작_속도: 12,
최대_속도: 9.5,   →   최대_속도: 12,
```
눈이 핑핑 돌아요. 몇 점까지 갈 수 있나요?
(`최대_속도` 도 같이 올려야 해요. 안 그러면 거기서 막힙니다)

**④ 편안한 산책 모드**
```js
스테이지마다_빨라짐: 0.5,   →   스테이지마다_빨라짐: 0,
```
보스를 아무리 많이 이겨도 속도가 그대로예요. 1000점 도전!

**⑤ 코인 부자**
```js
코인_점수: 10,   →   코인_점수: 100,
```
코인 하나에 100점! 코인만 노려보세요.

**⑥ 지옥 난이도**
```js
장애물_최소간격: 300,   →   장애물_최소간격: 150,
높은장애물_확률: 0.25,   →   높은장애물_확률: 0.8,
```
장애물이 촘촘하게, 그것도 높은 것만 나와요. 10점만 넘어도 대단합니다.

**⑦ 아이템 잔치**
```js
아이템_나올확률: 0.32,   →   아이템_나올확률: 1,
아이템_비율: { 강화: 4, 무적: 2, 회복: 3 },
                        →   아이템_비율: { 강화: 0, 무적: 1, 회복: 0 },
```
장애물마다 아이템이 뜨고, 전부 무적입니다. 거의 안 죽어요.
(비율은 합이 1이 아니어도 됩니다. `0` 은 "그건 안 나옴" 이라는 뜻이에요)

**⑧ 무기 부자**
```js
성_나오는_비율: 0.5,   →   성_나오는_비율: 0.1,
```
성이 자꾸자꾸 나와요. 다쳐도 금방 새 무기를 받을 수 있습니다.

**⑨ 한 번만 점프**
```js
두번_점프_가능: true,   →   두번_점프_가능: false,
```
공중 점프가 사라져요. 훨씬 어려워지고, **높이 뜬 아이템은 못 먹습니다.**

### 색깔 바꾸기

`색:` 부분의 색상 코드를 바꾸면 게임 분위기가 완전히 달라져요.

```js
색: {
  로봇:     "#ffd166",    // 로봇을 초록으로: "#06d6a0"
  장애물:   "#ef476f",    // 장애물을 보라로: "#9b5de5"
  하늘위:   "#1b2a4a",    // 낮 하늘로: "#87ceeb"
  하늘아래: "#3d5a80",    // 낮 하늘로: "#e0f4ff"
}
```

색상 코드는 구글에 **"color picker"** 를 검색하면 마음에 드는 색을 고를 수 있어요.

> 💡 **낮 게임으로 바꿔보기**
> 하늘 색을 밝게 바꾸면 별과 달이 안 어울려요.
> 그때는 `별` 색을 하늘색과 비슷하게 만들면 안 보이게 됩니다.

## 🧪 나만의 게임 만들어보기 (도전)

숫자 바꾸기가 익숙해졌다면, 이런 것도 해볼 수 있어요.

- 로봇이 더 크게 / 작게 → `game.js` 에서 `폭: 30, 높이: 34` 를 찾아보세요
- 새 무기 만들기 → `설정.무기들` 에 한 줄 추가 (이름·그림·위력·재장전만 있으면 돼요)
- 성 모양 바꾸기 → `성_그리기()` — 네모와 삼각형뿐이라 고치기 쉬워요
- 거인 모양 바꾸기 → `보스_그리기()` — 다리·몸통·머리·팔이 따로따로 그려져 있어요
- 코인을 더 자주 나오게 → `코인_나올확률: 0.6` 을 `1` 로
- 장애물 모양 바꾸기 → `그리기()` 안의 `// 장애물` 부분

**"이렇게 하면 어떻게 될까?"** 하고 궁금한 게 생기면, 그냥 해보세요.
직접 바꿔보고 확인하는 것이 가장 빨리 배우는 방법이에요.

## 어른을 위한 안내

### 파일 구조

```
game/
├── index.html   화면 뼈대 (점수판, 시작 화면)
├── style.css    화면 꾸미기
├── game.js      게임 본체 — 맨 위에 '설정' 이 모여 있습니다
├── sw.js        인터넷 없이도 열리게 해주는 파일
├── manifest.json  앱으로 설치할 때 쓰는 정보
└── icons/       홈 화면 아이콘 (로봇 모양)
```

### 홈 화면에 추가하기

**아이패드·아이폰**: 사파리에서 게임 주소를 열고 → 공유(⬆️) → 홈 화면에 추가
**안드로이드·데스크탑**: 크롬 주소창의 설치 아이콘

주소창 없이 전체 화면으로 열려서 앱처럼 쓸 수 있습니다.

### 아이와 함께 할 때

- **먼저 실컷 하게 두세요.** 재미있어야 고쳐보고 싶어집니다.
- 숫자 하나를 함께 바꾸고 **바로 확인**하는 경험이 중요합니다.
  위의 "달나라 점프"(중력 0.15)가 반응이 제일 좋습니다.
- 데스크탑이라면 VS Code 의 **Live Server** 를 쓰면 저장하는 순간 반영됩니다.
  (`SETUP-WINDOWS.md` 4단계 참고)
- 아이가 "이런 것도 돼요?" 라고 물으면, 대부분 됩니다. Claude 에게 물어보세요.

### 게임이 잘 안 될 때

- **화면이 안 나와요** → 브라우저를 새로고침 (주소 뒤에 `?v=99` 를 붙여보세요)
- **소리가 안 나요** → 오른쪽 위 🔊 버튼을 한 번 눌러보세요.
  휴대폰이 무음 모드면 소리가 안 납니다.
- **너무 어려워요** → `game.js` 에서 `시작_속도` 를 `3` 으로,
  `스테이지마다_빨라짐` 을 `0.2` 로, `보스_기본체력` 을 `3` 으로
  (또는 `로봇_체력` 을 `5` 로)
- **너무 쉬워요** → `보스_기본체력` 을 `6` 으로, `보스_공격간격` 을 `70` 으로,
  `장애물_최소간격` 을 `220` 으로
- **너무 쉬워요** → 위의 "지옥 난이도" 를 적용해보세요
