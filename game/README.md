## 🎮 게임하는 법

| 조작 | 하는 일 |
|---|---|
| 화면을 톡 | 점프 |
| 공중에서 한 번 더 톡 | **두 번 점프** (더 높이!) |

- 빨간 장애물에 부딪히면 끝나요
- 노란 코인을 먹으면 **10점** 보너스
- 오래 버틸수록 점점 빨라집니다

휴대폰을 **가로로 눕히면** 앞이 더 잘 보여서 유리해요.

## 🛠 게임을 내 맘대로 바꿔보기

`game.js` 파일을 열면 **맨 위에 숫자들이 모여** 있어요.
숫자를 바꾸고 저장한 다음, 게임 화면을 새로고침하면 바로 달라집니다.

**망가뜨릴 걱정은 하지 마세요.** 이상해지면 원래 숫자로 되돌리면 됩니다.

### 이걸 먼저 해보세요 (재미있는 순서대로)

**① 달나라 점프**
```js
중력: 0.55,   →   중력: 0.15,
```
아주 천천히 떠올랐다가 사르르 내려와요. 우주에 온 것 같아요.

**② 슈퍼 점프**
```js
점프_힘: 11,   →   점프_힘: 22,
```
화면 밖까지 날아갑니다. 장애물이 하나도 안 보여요!

**③ 초고속 모드**
```js
시작_속도: 4.2,   →   시작_속도: 12,
```
눈이 핑핑 돌아요. 몇 점까지 갈 수 있나요?

**④ 편안한 산책 모드**
```js
속도_증가: 0.00035,   →   속도_증가: 0,
```
아무리 오래 해도 빨라지지 않아요. 1000점 도전!

**⑤ 코인 부자**
```js
코인_점수: 10,   →   코인_점수: 100,
```
코인 하나에 100점! 코인만 노려보세요.

**⑥ 지옥 난이도**
```js
장애물_최소간격: 300,   →   장애물_최소간격: 150,
높은장애물_확률: 0.25,   →   높은장애물_확률: 0.8,
```
장애물이 촘촘하게, 그것도 높은 것만 나와요. 10점만 넘어도 대단합니다.

**⑦ 한 번만 점프**
```js
두번_점프_가능: true,   →   두번_점프_가능: false,
```
공중 점프가 사라져요. 훨씬 어려워집니다.

### 색깔 바꾸기

`색:` 부분의 색상 코드를 바꾸면 게임 분위기가 완전히 달라져요.

```js
색: {
  로봇:     "#ffd166",    // 로봇을 초록으로: "#06d6a0"
  장애물:   "#ef476f",    // 장애물을 보라로: "#9b5de5"
  하늘위:   "#1b2a4a",    // 낮 하늘로: "#87ceeb"
  하늘아래: "#3d5a80",    // 낮 하늘로: "#e0f4ff"
}
```

색상 코드는 구글에 **"color picker"** 를 검색하면 마음에 드는 색을 고를 수 있어요.

> 💡 **낮 게임으로 바꿔보기**
> 하늘 색을 밝게 바꾸면 별과 달이 안 어울려요.
> 그때는 `별` 색을 하늘색과 비슷하게 만들면 안 보이게 됩니다.

## 🧪 나만의 게임 만들어보기 (도전)

숫자 바꾸기가 익숙해졌다면, 이런 것도 해볼 수 있어요.

- 로봇이 더 크게 / 작게 → `game.js` 에서 `폭: 30, 높이: 34` 를 찾아보세요
- 코인을 더 자주 나오게 → `코인_나올확률: 0.6` 을 `1` 로
- 장애물 모양 바꾸기 → `그리기()` 안의 `// 장애물` 부분

**"이렇게 하면 어떻게 될까?"** 하고 궁금한 게 생기면, 그냥 해보세요.
직접 바꿔보고 확인하는 것이 가장 빨리 배우는 방법이에요.

## 어른을 위한 안내

### 파일 구조

```
game/
├── index.html   화면 뼈대 (점수판, 시작 화면)
├── style.css    화면 꾸미기
├── game.js      게임 본체 — 맨 위에 '설정' 이 모여 있습니다
├── manifest.json  앱으로 설치할 때 쓰는 정보
└── icons/       홈 화면 아이콘 (로봇 모양)
```

### 홈 화면에 추가하기

**아이패드·아이폰**: 사파리에서 게임 주소를 열고 → 공유(⬆️) → 홈 화면에 추가
**안드로이드·데스크탑**: 크롬 주소창의 설치 아이콘

주소창 없이 전체 화면으로 열려서 앱처럼 쓸 수 있습니다.

### 아이와 함께 할 때

- **먼저 실컷 하게 두세요.** 재미있어야 고쳐보고 싶어집니다.
- 숫자 하나를 함께 바꾸고 **바로 확인**하는 경험이 중요합니다.
  위의 "달나라 점프"(중력 0.15)가 반응이 제일 좋습니다.
- 데스크탑이라면 VS Code 의 **Live Server** 를 쓰면 저장하는 순간 반영됩니다.
  (`SETUP-WINDOWS.md` 4단계 참고)
- 아이가 "이런 것도 돼요?" 라고 물으면, 대부분 됩니다. Claude 에게 물어보세요.

### 게임이 잘 안 될 때

- **화면이 안 나와요** → 브라우저를 새로고침 (주소 뒤에 `?v=99` 를 붙여보세요)
- **소리가 안 나요** → 오른쪽 위 🔊 버튼을 한 번 눌러보세요.
  휴대폰이 무음 모드면 소리가 안 납니다.
- **너무 어려워요** → `game.js` 에서 `시작_속도` 를 `3` 으로, `속도_증가` 를 `0.0002` 로
- **너무 쉬워요** → 위의 "지옥 난이도" 를 적용해보세요
