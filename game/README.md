# 점프! 로봇 🤖

한 손가락으로 하는 점프 게임입니다.

**게임 주소** → `https://logos113.github.io/Project-begins/game/`

---

## 🎮 게임하는 법

| 조작 | 하는 일 |
|---|---|
| 화면을 톡 | 점프 |
| 공중에서 한 번 더 톡 | **두 번 점프** (더 높이!) |
| **발사** 버튼 | 미사일 쏘기 (보스와 싸울 때만 나타나요) |

- 화면 위에 **♥ 가 세 칸** 있어요. **세 번 맞으면** 끝납니다
- 맞은 직후에는 잠깐 **깜빡이는데, 그동안은 안 맞아요**
- 노란 코인을 먹으면 **10점** 보너스
- **파란 아이템**을 먹으면 미사일이 하나 생겨요
- 속도는 **스테이지 안에서 계속 같아요.** 보스를 이겨야 다음 스테이지로
  넘어가면서 조금 빨라집니다

휴대폰을 **가로로 눕히면** 앞이 더 잘 보여서 유리해요.

## 👾 보스와 싸우기

**파란 아이템 3개**를 모으고 **300점**을 넘기면 보라색 보스가 날아옵니다.
아이템이 모자라면 보스는 그냥 지나가요. **아이템이 곧 입장권**인 셈입니다.

싸우는 동안에는 **장애물이 나오지 않아요.** 보스만 신경 쓰면 됩니다.

### 어떻게 이기나

오른쪽 아래 **발사** 버튼을 누르면 미사일이 나갑니다.
미사일은 보스를 따라가니까 겨냥하지 않아도 돼요. **세 번 맞히면 이깁니다.**

이기면 **200점**을 받고, 모은 미사일은 다 쓴 것으로 칩니다.
다음 보스는 600점, 그다음은 900점에 옵니다. 그때까지 또 모으면 됩니다.

### 스테이지 — 속도가 올라가는 유일한 순간

**보스를 이길 때만** 스테이지가 1 올라가고, 그때 조금 빨라집니다.
한 스테이지 안에서는 처음부터 끝까지 **같은 속도**로 달려요.

보스가 그냥 지나가거나(아이템 부족) 물러가면 **스테이지는 그대로**입니다.
즉 아이템을 안 모으면 게임은 계속 편안한 속도로 흘러가요.
빨라지는 것도, 200점 보너스도, 이겨야 받습니다.

> 예전에는 시간이 흐를수록 계속 빨라졌는데, **20초면 최고 속도**에 닿을 만큼
> 가팔랐습니다. 지금은 내가 이긴 만큼만 빨라집니다.

### 어떻게 피하나

보스가 쏘는 붉은 공은 **두 가지**입니다. 날아오는 높이를 보고 정하세요.

| 날아오는 높이 | 해야 할 것 |
|---|---|
| 발밑으로 낮게 | **점프**해서 넘기 |
| 머리 위로 높게 | **가만히 서 있기** (뛰면 맞아요!) |

맞으면 ♥ 가 한 칸 줄어듭니다. 세 칸을 다 잃으면 끝나요.
미사일이 다 떨어지면 보스는 잠시 뒤 물러갑니다.

### 보스가 너무 어렵거나 쉬우면

`game.js` 맨 위에서 숫자를 바꿔보세요.

```js
로봇_체력: 3,           // 1 로 하면 예전처럼 한 방에 끝나요
무적_시간: 75,          // 맞은 뒤 깜빡이는 길이 (60 이 1초쯤)
보스_필요_아이템: 3,    // 2 로 하면 보스를 더 자주 만나요
보스_체력: 3,           // 1 로 하면 한 방에 쓰러져요
보스_공격간격: 95,      // 200 으로 하면 훨씬 덜 쏴요 (쉬워짐)
미사일_유도: 0.14,      // 0 으로 하면 똑바로만 날아가요 (훨씬 어려움)
```

> **무적_시간은 0 으로 두지 마세요.** 장애물에 부딪히면 몸이 겹쳐 있는 동안
> 세 칸이 순식간에 다 사라집니다. 체력이 있으나 마나 해집니다.

> **미사일_유도 이야기** — 처음에는 미사일이 똑바로만 날아가게 만들었는데,
> 보스가 위아래로 떠다녀서 **명중률이 33%** 밖에 안 됐습니다.
> 아이템 3개를 모아야 보스가 나오는데 3발 중 1발만 맞으면 이길 수가 없죠.
> 그래서 살짝 따라가게 고쳤더니 100%가 되었습니다.
> 겨냥하는 재미를 원하면 `0` 으로 두고, 대신 아이템을 많이 모으세요.

## 🛠 게임을 내 맘대로 바꿔보기

`game.js` 파일을 열면 **맨 위에 숫자들이 모여** 있어요.
숫자를 바꾸고 저장한 다음, 게임 화면을 새로고침하면 바로 달라집니다.

**망가뜨릴 걱정은 하지 마세요.** 이상해지면 원래 숫자로 되돌리면 됩니다.

### 이걸 먼저 해보세요 (재미있는 순서대로)

**① 달나라 점프**
```js
중력: 0.55,   →   중력: 0.15,
```
아주 천천히 떠올랐다가 사르르 내려와요. 우주에 온 것 같아요.

**② 슈퍼 점프**
```js
점프_힘: 11,   →   점프_힘: 22,
```
화면 밖까지 날아갑니다. 장애물이 하나도 안 보여요!

**③ 초고속 모드**
```js
시작_속도: 3.5,   →   시작_속도: 12,
최대_속도: 9,     →   최대_속도: 12,
```
눈이 핑핑 돌아요. 몇 점까지 갈 수 있나요?
(`최대_속도` 도 같이 올려야 해요. 안 그러면 거기서 막힙니다)

**④ 편안한 산책 모드**
```js
스테이지마다_빨라짐: 0.45,   →   스테이지마다_빨라짐: 0,
```
보스를 아무리 많이 이겨도 속도가 그대로예요. 1000점 도전!

**⑤ 코인 부자**
```js
코인_점수: 10,   →   코인_점수: 100,
```
코인 하나에 100점! 코인만 노려보세요.

**⑥ 지옥 난이도**
```js
장애물_최소간격: 300,   →   장애물_최소간격: 150,
높은장애물_확률: 0.25,   →   높은장애물_확률: 0.8,
```
장애물이 촘촘하게, 그것도 높은 것만 나와요. 10점만 넘어도 대단합니다.

**⑦ 한 번만 점프**
```js
두번_점프_가능: true,   →   두번_점프_가능: false,
```
공중 점프가 사라져요. 훨씬 어려워집니다.

### 색깔 바꾸기

`색:` 부분의 색상 코드를 바꾸면 게임 분위기가 완전히 달라져요.

```js
색: {
  로봇:     "#ffd166",    // 로봇을 초록으로: "#06d6a0"
  장애물:   "#ef476f",    // 장애물을 보라로: "#9b5de5"
  하늘위:   "#1b2a4a",    // 낮 하늘로: "#87ceeb"
  하늘아래: "#3d5a80",    // 낮 하늘로: "#e0f4ff"
}
```

색상 코드는 구글에 **"color picker"** 를 검색하면 마음에 드는 색을 고를 수 있어요.

> 💡 **낮 게임으로 바꿔보기**
> 하늘 색을 밝게 바꾸면 별과 달이 안 어울려요.
> 그때는 `별` 색을 하늘색과 비슷하게 만들면 안 보이게 됩니다.

## 어른을 위한 안내

### 파일 구조

```
game/
├── index.html   화면 뼈대 (점수판, 시작 화면)
├── style.css    화면 꾸미기
├── game.js      게임 본체 — 맨 위에 '설정' 이 모여 있습니다
├── sw.js        인터넷 없이도 열리게 해주는 파일
├── manifest.json  앱으로 설치할 때 쓰는 정보
└── icons/       홈 화면 아이콘 (로봇 모양)
```

### 홈 화면에 추가하기

**아이패드·아이폰**: 사파리에서 게임 주소를 열고 → 공유(⬆️) → 홈 화면에 추가
**안드로이드·데스크탑**: 크롬 주소창의 설치 아이콘

주소창 없이 전체 화면으로 열려서 앱처럼 쓸 수 있습니다.

### 아이와 함께 할 때

- **먼저 실컷 하게 두세요.** 재미있어야 고쳐보고 싶어집니다.
- 숫자 하나를 함께 바꾸고 **바로 확인**하는 경험이 중요합니다.
  위의 "달나라 점프"(중력 0.15)가 반응이 제일 좋습니다.
- 데스크탑이라면 VS Code 의 **Live Server** 를 쓰면 저장하는 순간 반영됩니다.
  (`SETUP-WINDOWS.md` 4단계 참고)
- 아이가 "이런 것도 돼요?" 라고 물으면, 대부분 됩니다. Claude 에게 물어보세요.

### 게임이 잘 안 될 때

- **화면이 안 나와요** → 브라우저를 새로고침 (주소 뒤에 `?v=99` 를 붙여보세요)
- **소리가 안 나요** → 오른쪽 위 🔊 버튼을 한 번 눌러보세요.
  휴대폰이 무음 모드면 소리가 안 납니다.
- **너무 어려워요** → `game.js` 에서 `시작_속도` 를 `3` 으로,
  `스테이지마다_빨라짐` 을 `0.2` 로 (또는 `로봇_체력` 을 `5` 로)
- **너무 쉬워요** → 위의 "지옥 난이도" 를 적용해보세요
