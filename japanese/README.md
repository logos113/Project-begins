# 오늘의 일본어 여행 회화 (Travel Japanese)

일본 여행에서 **바로 쓰는 표현**을 하루 3개씩 익히고, 잊어버릴 때쯤 다시 물어봐 주는 웹페이지입니다.

- 데이터: **없음** — 표현이 `phrases.js` 파일 안에 그대로 들어 있습니다
- 인터넷: **필요 없음** — 한 번 열어두면 비행기 안에서도 그대로 동작합니다
- 비용: **0원**

논문 앱(`/Project-begins/`)과는 폴더로 완전히 분리되어 있습니다.
서로 영향을 주지 않고, 홈 화면에도 따로 추가할 수 있습니다.

## 2단계 — 하루 쓰는 법

하루 3분이면 됩니다.

1. **앱을 엽니다.** 오늘의 표현 3개가 이미 골라져 있습니다.
2. 한국어 뜻을 보고 **일본어를 떠올려 봅니다.**
3. **`일본어 확인하기`** 를 눌러 맞는지 봅니다.
4. **🔊 발음 듣기** 로 소리를 확인하고, 한 번 소리 내어 따라 합니다.
5. **`외웠어요`** 를 누릅니다 → 내일 다시 물어봅니다.
6. 다음 날부터는 화면 위에 **`복습 퀴즈 (3)`** 처럼 숫자가 뜹니다. 그것부터 누르시면 됩니다.

이게 전부입니다. 새 표현 3개 + 복습 몇 개.

## 3단계 — 화면 설명

### 위쪽 설정 세 가지

| 설정 | 무엇을 바꾸나 |
|---|---|
| **상황** | 특정 장면의 표현만 봅니다. 식당 갈 일이 있으면 '식당 · 카페'로 두세요 |
| **연습 방식** | 뜻을 먼저 볼지, 일본어를 먼저 볼지, 아니면 그냥 다 볼지 |
| **발음 표기** | 히라가나 · 로마자 · 한글 발음 중 무엇을 보여줄지 |

**연습 방식**을 고르는 기준:

- `한국어 뜻 보고 → 일본어 떠올리기` — **말하기 연습.** 실제로 입을 떼야 하는 상황과 같습니다
- `일본어 보고 → 뜻 떠올리기` — **읽기 연습.** 메뉴판·안내판을 읽을 때 도움이 됩니다
- `바로 다 보여주기` — 연습 없이 훑어볼 때. 비행기 안에서 복습하듯

**발음 표기**에서 `히라가나만`을 고르면 일본 글자에 눈이 익습니다.
급할 때는 `한글 발음만`으로 두면 바로 읽을 수 있습니다.

### 버튼

- **☆ (카드 오른쪽 위)** — 자주 볼 표현을 저장합니다. `저장한 표현` 버튼으로 모아 볼 수 있습니다
- **다른 표현 보기** — 오늘 것 말고 다른 3개를 봅니다
- **복습 퀴즈** — 복습할 차례가 된 표현을 4지선다로 물어봅니다

### 위쪽 숫자 세 개

- **○일 연속** — 며칠 이어서 공부했는지. 하루 쉬면 1부터 다시 셉니다
- **○ / 92 표현** — 지금까지 '외웠어요'를 누른 개수
- **○개 복습할 차례** — 오늘 다시 볼 표현의 수

## 복습은 어떤 규칙으로 오나요

'외웠어요'를 누르거나 퀴즈에서 맞히면, 다음에 물어보기까지의 간격이 점점 벌어집니다.

```
1일 →  3일 →  7일 →  14일 →  30일
```

틀리면 처음(1일 뒤)으로 돌아갑니다.

잊어버리기 직전에 다시 보는 것이 가장 오래 남는다는, 오래 검증된 방식입니다.
매일 전부를 다시 보지 않아도 되니 시간도 훨씬 적게 듭니다.

간격을 바꾸고 싶으면 `app.js` 의 이 부분만 고치면 됩니다.

```js
const 복습_간격일 = [1, 3, 7, 14, 30];
```

## 발음 듣기에 대해

기기 안에 들어 있는 일본어 음성을 씁니다. 인터넷도, 회원가입도, 비용도 들지 않습니다.

한자는 읽는 방법이 여러 가지라 잘못 읽는 일이 있어서,
**히라가나로 풀어 쓴 '읽기'를 읽힙니다.** 그래서 발음이 어긋나지 않습니다.

**소리가 어색하게 들린다면** 기기에 일본어 음성이 없는 경우입니다.

- **아이폰·아이패드**: 설정 → 손쉬운 사용 → 말하기 콘텐츠 → 음성 → 일본어 추가
- **윈도우**: 설정 → 시간 및 언어 → 언어 → 언어 추가 → 일본어 (음성 포함)
- **안드로이드**: 설정 → 접근성 → 텍스트 음성 변환 → 언어 데이터 설치

없어도 앱은 그대로 동작합니다. 한글 발음 표기를 보시면 됩니다.

## 표현을 더 넣고 싶을 때

`japanese/phrases.js` 파일만 열면 됩니다. 아래 모양을 그대로 복사해 한 칸 더 적으시면 됩니다.

```js
  {
    아이디: "shoku-24",              // 겹치지 않는 이름표
    상황: "식당",                     // 상황목록에 있는 값 중 하나
    난이도: 2,                        // 1 = 먼저 배울 것, 2 = 익숙해진 뒤
    일본어: "おかわりください",
    읽기: "おかわりください",           // 한자를 히라가나로 푼 것 (발음 듣기에 쓰입니다)
    로마자: "okawari kudasai",
    한글음: "오카와리 쿠다사이",
    뜻: "한 그릇 더 주세요",
    메모: "밥·국을 더 달라고 할 때. 무료로 더 주는 가게가 많습니다.",
  },
```

**주의할 점 하나** — 아이디는 나중에 바꾸지 마세요.
"이 표현을 익혔다 / 언제 복습할 차례다" 라는 기록이 아이디를 기준으로 저장되기 때문에,
아이디를 바꾸면 그 기록이 엉뚱한 표현을 가리키게 됩니다.
순서를 바꾸거나 중간에 끼워 넣는 것은 괜찮습니다.

다 적은 뒤에는 아래 검사를 한 번 돌려보시면 빠뜨린 항목이 있는지 알려 줍니다.

## 고친 뒤 확인하기

```bash
npm install jsdom
node tests/japanese.test.mjs
```

80가지를 자동으로 확인합니다. 표현 자료가 규칙에 맞는지, 오늘의 표현을 고르는 규칙이
제대로 도는지, 날짜 계산과 복습 예약이 맞는지, 실제로 버튼을 눌렀을 때 동작하는지까지 봅니다.

화면 모양을 눈으로 확인하려면:

```bash
npm install playwright
npx playwright install chromium
node tools/screenshot_ja.mjs
```

휴대폰·아이패드·데스크탑·퀴즈 화면의 스크린샷 4장이 만들어집니다.

아이콘을 다시 만들려면 (색이나 모양을 바꾼 뒤):

```bash
python3 tools/make_icons_ja.py
```

## 알아두실 점

- 학습 기록은 **이 기기 안에만** 저장됩니다. 다른 기기로 넘어가지 않고,
  브라우저 기록을 지우면 함께 지워집니다. 사파리 비공개 브라우징에서는 기록이 남지 않습니다.
- 한글 발음 표기는 **정확한 발음이 아니라 급할 때 쓰는 비상용**입니다.
  일본어에는 한글로 적을 수 없는 소리(つ, ざ, 장음 등)가 있습니다. 🔊 소리를 듣는 쪽이 언제나 정확합니다.
- 표현은 모두 **정중한 말투(です·ます)** 로 적었습니다. 가게·역·호텔에서 처음 만나는 사람에게
  그대로 쓰면 실례가 되지 않습니다.
