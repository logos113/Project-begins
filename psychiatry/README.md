# 오늘의 정신의학 논문 (Psychiatry Daily Digest)

신뢰할 만한 학술지에 최근 발표된 정신의학 논문 중 **매일 3편**을 골라
제목·저자·핵심 결론을 한 화면에서 보여주는 웹페이지입니다.

- 주소: `https://logos113.github.io/Project-begins/psychiatry/`
- 파일: 이 폴더(`psychiatry/`) 안에 전부 들어 있습니다
- 데이터: 미국 국립의학도서관 **PubMed** 공개 API (무료, 회원가입 불필요)
- 비용: **0원**

> 이 문서는 **논문 앱 하나**에 대한 설명서입니다.
> 인터넷에 올리는 법, 홈 화면에 추가하는 법, 다른 기기에서 이어서 작업하는 법처럼
> 세 앱에 공통인 이야기는 저장소 첫 문서 [../README.md](../README.md) 에 있습니다.

---

## 1단계 — 파일 3개가 하는 일

웹페이지는 보통 파일 3개로 이뤄집니다. 사람으로 비유하면 이렇습니다.

| 파일 | 역할 | 비유 |
|---|---|---|
| `index.html` | 무엇이 있는지 (제목, 버튼, 목록) | **뼈대** |
| `style.css` | 어떻게 보일지 (색, 크기, 여백) | **옷** |
| `app.js` | 무엇을 할지 (논문 가져오기, 버튼 반응) | **두뇌** |

세 파일 모두 **메모장으로 열어서 고칠 수 있는 그냥 글자 파일**입니다.
특별한 프로그램이 필요 없습니다. 한 줄 한 줄 한국어 주석을 달아두었으니
위에서부터 천천히 읽어보시면 무슨 일이 일어나는지 보입니다.

> 참고: 이 코드는 배우기 쉽도록 변수 이름을 **한글로** 지었습니다.
> 실제 개발 현장에서는 영어를 씁니다(`papers`, `loadPapers` 등).
> 익숙해지신 뒤에 영어로 바꿔보는 것도 좋은 연습입니다.

### 이 페이지가 동작하는 순서

```
페이지 열림
   ↓
[app.js] 검색 조건을 문장으로 조립
         예: (JAMA Psychiatry 또는 Lancet Psychiatry ...) 그리고 최근 30일
   ↓
[app.js] PubMed에 물어봄  →  논문 번호 60개를 받음
   ↓
[app.js] 오늘 날짜를 기준으로 그중 3개를 고름
         (그래서 하루 동안은 같은 3편, 다음 날엔 다른 3편)
   ↓
[app.js] 그 3편의 제목·저자·초록을 다시 받아옴
   ↓
[app.js] 카드 모양으로 화면에 그림  →  [style.css]가 예쁘게 꾸밈
```

## 2단계 — 직접 고쳐보기

코딩은 읽는 것보다 **고쳐보는 것**으로 빨리 늡니다.
아래는 안전하게 바꿔볼 수 있는 것들입니다.

- **아이패드**: 위의 "코드 고치는 방법"대로 고치고 **Commit** → 1~2분 뒤 배포 주소를 새로고침
- **데스크탑**: 파일을 고치고 **저장** → 브라우저 새로고침(F5)

### (1) 하루에 보여줄 편수 바꾸기 — `app.js`

```js
const 보여줄_편수 = 3;      // 이 숫자를 5로 바꾸면 5편이 나옵니다
```

### (2) 학술지 추가·제거하기 — `app.js`

`정신의학_학술지` 목록에 한 줄 추가하면 됩니다.

```js
const 정신의학_학술지 = [
  "Lancet Psychiatry",
  "JAMA Psychiatry",
  "Sleep Med",            // ← 이렇게 추가
];
```

이름은 PubMed의 **공식 약어**를 써야 합니다. 확인하는 방법:
PubMed에서 그 학술지 논문 아무거나 열면 제목 위에 약어가 나옵니다
(예: `Sleep Med. 2026 Mar;` → 약어는 `Sleep Med`).

### (3) 관심 분야 추가하기 — `index.html` + `app.js`

두 곳을 함께 고쳐야 합니다. 예로 "여성 정신건강"을 추가한다면,

`index.html` 의 분야 목록에 한 줄:
```html
<option value="women">여성 정신건강</option>
```

`app.js` 의 `분야별_키워드` 에 한 줄:
```js
women: ["perinatal", "postpartum", "premenstrual", "menopause"],
```

> `value="women"` 과 `women:` 의 **이름이 똑같아야** 연결됩니다. 여기가 자주 틀리는 부분입니다.

### (4) 색깔 바꾸기 — `style.css`

맨 위 `:root` 안의 색상 코드만 바꾸면 전체 분위기가 바뀝니다.

```css
--accent: #1c5d7a;   /* 강조색. 예: #7a1c3d 로 바꾸면 자주색 계열 */
```

색상 코드는 구글에 "color picker"를 검색하면 쉽게 고를 수 있습니다.

### (5) 저장한 논문은 어디에 보관되나 — `app.js`

논문 카드의 **☆ 저장** 버튼을 누르면 브라우저 안의 저장 공간(localStorage)에 보관됩니다.

- **이 기기, 이 브라우저에만** 저장됩니다. 서버로 전송되지 않아 다른 사람은 볼 수 없습니다.
- 아이패드에서 저장한 것은 데스크탑에서 보이지 않습니다 (기기마다 따로입니다).
- 사파리 `방문 기록 및 웹사이트 데이터 지우기` 를 하면 함께 지워집니다.
- 용량 절약을 위해 초록 전문은 저장하지 않습니다. 전문은 PubMed 링크로 보세요.

보관함 이름을 바꾸고 싶으면 `app.js` 의 이 부분을 고치면 됩니다.

```js
const 북마크_보관함_이름 = "psychiatry-digest-bookmarks";
```

> 이름을 바꾸면 **기존에 저장해둔 논문이 보이지 않게 됩니다.** (지워지는 것은 아니고,
> 다른 서랍을 열게 되는 것입니다) 특별한 이유가 없으면 그대로 두세요.

### (6) 학술지 우선순위 조정하기 — `app.js`

화면에서 **"권위 높은 학술지 우선"**을 고르면, 등급이 높은 학술지 논문이
더 자주 보입니다. 등급은 `app.js` 의 `학술지_등급` 표에 적혀 있습니다.

```js
const 학술지_등급 = {
  "JAMA": 5,                 // 5등급 — 가장 자주 보임
  "Lancet Psychiatry": 4,
  "Psychol Med": 2,
  "J Affect Disord": 1,      // 1등급 — 가끔 보임
};
```

**이 등급은 절대적인 기준이 아닙니다.** 전공하신 분의 판단이 더 정확할 수 있으니
자유롭게 고치세요. 숫자를 올리면 더 자주, 내리면 덜 보입니다.
표에 없는 학술지는 자동으로 1등급이 됩니다.

> **Impact Factor를 직접 가져오지 않는 이유**
> IF는 Clarivate 라는 회사의 유료 데이터라 무료로 가져올 수 없고,
> 수치를 그대로 옮겨 적는 것도 라이선스 문제가 있습니다.
> PubMed 역시 IF 정보를 제공하지 않습니다.
> 그래서 대략적인 위상을 등급으로 나누어 직접 적어두는 방식을 씁니다.

낮은 등급도 완전히 배제되지는 않습니다. 365일치로 확인한 결과,
5등급은 약 160회, 1등급은 약 26회 등장합니다 (매일 3편 기준).

### (7) 홈 화면 아이콘 바꾸기

아이콘 그림은 `tools/make_icons.py` 가 만들어 냅니다.
맨 위의 색깔만 바꿔도 분위기가 달라집니다.

```python
배경색   = (0x1c, 0x5d, 0x7a)   # 진한 청록  (숫자 3개 = 빨강, 초록, 파랑)
종이색   = (0xff, 0xff, 0xff)   # 흰색
```

고친 뒤 `python3 tools/make_icons.py` 를 실행하면 `icons/` 안의 그림 4개가 새로 만들어집니다.
**아이패드에서는 이 명령을 실행할 수 없으니**, 원하시는 색이나 모양을 저에게 말씀해 주세요.

## 문제가 생겼을 때

### "논문을 불러오지 못했습니다" 라고 나올 때

**① 병원·회사 내부망인가요?**
보안 정책으로 외부 접속이 막혀 있을 수 있습니다. 개인 노트북이나 휴대폰(LTE/5G)에서 열어보세요.

**② 아이패드·아이폰에서 파일을 직접 열지 않으셨나요?**
이건 고칠 수 없는 제약입니다. GitHub Pages 주소(`.../Project-begins/psychiatry/`)로 접속해 주세요.

**③ 데스크탑에서 브라우저가 파일을 직접 여는 걸 막고 있나요?**
`index.html` 을 더블클릭했을 때만 안 된다면, 아주 작은 "서버"를 켜서 열면 해결됩니다.
파이썬이 깔려 있다면(맥은 기본 설치되어 있습니다), 이 폴더에서 터미널을 열고:

```bash
python3 -m http.server 8000
```

그리고 브라우저에서 `http://localhost:8000` 을 엽니다. 끄려면 터미널에서 `Ctrl + C`.

**④ 무슨 일이 일어났는지 직접 보고 싶다면**
데스크탑이라면 **F12**(맥은 `Cmd + Option + I`)를 누르고 **Console** 탭을 보세요.
빨간 글씨가 실제 오류 내용입니다.

아이패드에는 개발자 도구가 없습니다. 대신 **화면에 표시된 오류 메시지를 그대로**
(스크린샷도 좋습니다) 알려주시면 원인을 찾아드리겠습니다.

### 논문이 너무 적게 나올 때

"발표 시기"를 **최근 90일**이나 **최근 1년**으로 늘려보세요.
특정 분야를 고르면 대상이 크게 줄어드는 것이 정상입니다.

## 다음에 이어서 할 일

### 1순위 — 초록을 AI로 요약하기

지금은 초록에서 결론에 해당하는 부분을 **규칙으로 찾아 발췌**합니다.
그래서 학술지마다 다른 초록 형식을 하나씩 대응해야 하고, 실제로 이런 문제들을 겪었습니다.

- 항목이 나뉜 초록 / 한 덩어리 초록의 처리 방식이 다름
- `et al.` `vs.` 같은 약어에서 문장이 잘못 끊김
- 편집자 평가표가 결론으로 잡힘 (ACP Journal Club)

AI 요약은 **읽고 이해해서 다시 쓰는 방식**이라 형식과 무관합니다.
위 문제들이 대부분 사라지고, **한국어로 바로** 받을 수 있어 번역 문제도 함께 해결됩니다.

**시작하려면**

1. `console.anthropic.com` 가입 → 잔여 크레딧 확인
   (claude.ai 구독과는 **별개의 결제**입니다. 지갑이 따로예요)
2. API 키 발급
3. Claude에게 "AI 요약 붙여줘" 라고 요청

**비용**: 매일 3편 기준 월 300~600원. 5달러 충전하면 2~4년 씁니다.

**설계할 때 지켜야 할 것**

- 키는 **코드에 넣지 않습니다.** 이 페이지는 공개 사이트입니다.
  화면에 입력란을 두고 브라우저에만 저장하는 방식(북마크와 동일)을 씁니다.
- 원문 초록을 **항상 함께** 보여줍니다. AI가 없는 내용을 지어낼 수 있으므로,
  의학 정보에서는 원문 확인 경로가 반드시 남아 있어야 합니다.
- 지금의 발췌 방식을 **폴백으로 유지**합니다.
  키가 없거나 호출이 실패해도 페이지는 지금처럼 동작해야 합니다.

## 알아두실 점

- 이 도구는 **문헌 탐색을 돕기 위한 것**입니다. 핵심 결론은 초록 원문을 그대로 보여줄 뿐이며,
  진료 판단의 근거로 삼기 전에 반드시 **원문 전체를 직접 확인**하시기 바랍니다.
- PubMed API는 무료지만 **초당 3회** 요청 제한이 있습니다. 이 페이지는 한 번 열 때 2회만
  요청하므로 문제가 없습니다. 나중에 기능을 크게 늘린다면
  [NCBI API 키](https://www.ncbi.nlm.nih.gov/account/)를 무료로 발급받아 초당 10회로 늘릴 수 있습니다.
