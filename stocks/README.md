## ⏳ 아직 안 한 것 — 나중에 할 일

### 1. FRED 열쇠 받기 (미국 경제지표 발표일)

**지금 미국 CPI 발표일은 안 나옵니다.** 다른 것들은 다 나옵니다.

왜 안 되나 — BLS(미국 노동통계국)가 **도메인 전체를 막아두었습니다**(403).
RSS 도, 일정 페이지도 전부 막혀 있습니다. 위장해서 뚫지 않습니다.

어떻게 풀 수 있나 — **FRED**(세인트루이스 연방준비은행)가 같은 자료를
API 로 내어줍니다. 두드려보니 `api_key is not set` 이라고 답했습니다.
**막은 게 아니라 열쇠를 넣으라는 뜻**입니다.

하는 법 (5분, 무료, 한 번이면 끝):

1. https://fredaccount.stlouisfed.org/apikeys 에서 열쇠 발급 (이메일 가입)
2. 이 저장소 → **Settings → Secrets and variables → Actions**
   → **New repository secret**
   - 이름: `FRED_API_KEY`
   - 값: 발급받은 열쇠
3. Claude 에게 "FRED 열쇠 넣었어" 라고 알려주세요. 코드를 붙이겠습니다.

**얻는 것** — CPI 하나가 아닙니다. 고용보고서·GDP·PPI·소매판매 같은
미국 주요 지표 발표일을 **전부, 공식 출처로** 가져올 수 있습니다.
지금 '매월 첫째 금요일' 로 계산하고 있는 고용보고서도 실제 발표일로
바뀌어 더 정확해집니다.

> 안 해도 됩니다. FOMC·금통위·고용보고서·옵션만기는 이미 나옵니다.

## 어떻게 돌아가나

```
매일 아침 06:10 과 07:40 (한국시간)
  깃허브 일꾼이 저절로 깨어남
    → 뉴스 RSS 19곳에서 모으기
    → 시세 (지수·환율·코인)
    → 일정 (계산 + 연준·한국은행에서 긁어오기)
    → stocks/data/latest.json 으로 저장소에 올림

앱을 열면
  → 그 JSON 을 읽어서 화면에 그립니다
```

### 왜 이렇게 하나

이 저장소의 앱들은 **서버가 없는 정적 페이지**입니다. 스스로 뉴스를
모을 수 없고, 브라우저가 남의 사이트를 직접 읽는 것도 거의 다
막힙니다(CORS). 그래서 일꾼이 대신 모아 두고 앱은 그것만 읽습니다.

덕분에 생기는 좋은 점이 있습니다.

- 열쇠가 화면에 노출될 일이 없습니다 (앱은 남의 사이트를 안 부릅니다)
- 비행기 모드에서도 마지막 브리핑이 보입니다
- 공개 저장소라 일꾼이 **무료**입니다

### 깃허브 cron 은 정시를 약속하지 않습니다

몇 분에서 수십 분까지 늦게 깨어납니다. 그래서 **두 번** 돌려둡니다.
한 번이 늦으면 다른 한 번이 채웁니다.

## 무엇을 모으나

### 시세

코스피 · 코스닥 · S&P500 · 나스닥 · 원달러환율,
비트코인 · 이더리움 · 리플 · 솔라나.

> ⚠️ **참고용입니다.** 무료로 열어둔 곳에서 가져오는 값이라 거래소
> 공식 종가와 몇 분 차이가 날 수 있습니다. 매매에 쓰실 값이라면
> 증권사 화면을 보세요.

변동률은 **직전 거래일 종가 대비**입니다. 휴장일이 끼어도 제대로
세도록, 값이 있는 날만 골라 마지막 둘을 비교합니다.

하루에 **15% 넘게** 움직인 것으로 나오면 변동률을 비웁니다 —
그쯤 되면 '진짜 폭락' 보다 '잘못 읽었을' 확률이 높습니다.

### 뉴스

| 갈래 | 출처 |
|---|---|
| 한국 | 연합뉴스, 한국경제, 매일경제, 이데일리, 머니투데이 |
| 미국 | CNBC, MarketWatch, Investing |
| 코인 | CoinDesk, Cointelegraph, Decrypt, The Block, 코인데스크코리아 |

갈래마다 12건씩. 48시간 안의 것만, 겹치는 것은 하나로 줄여서.

`[게시판]` `[부고]` 같은 보도자료는 거릅니다. 단 `[속보]` `[단독]` 은
남기고, '인사혁신처' 처럼 멀쩡한 기사를 지우지 않도록 **맨 앞에 붙은
머리표만** 봅니다.

한 곳이 죽어도 건너뜁니다. 어디가 왜 실패했는지는 브리핑 안의
`출처상태` 에 적힙니다.

### 일정

**모르는 날짜는 지어내지 않습니다.** 투자 화면에서 제일 나쁜 일은
그럴듯하게 틀린 날짜를 자신 있게 보여주는 것입니다.

| 갈래 | 어디서 |
|---|---|
| 미국 고용보고서(첫째 금요일), 옵션만기(둘째 목요일), 네 마녀의 날, 요일로 정해지는 휴장일 | **계산** — 달력만 있으면 누구나 같은 답 |
| FOMC, 금통위 | **공식 사이트에서 긁어옴** — 연준·한국은행 |
| 미국 CPI, 설·추석 | **`calendar.json` 에 손으로** |

긁어온 일정에는 **출처와 원문 주소**가 붙습니다. 의심스러우면 바로
확인하세요.

구조가 바뀌어 못 읽으면 **빈 목록**을 돌려줍니다. FOMC 가 8개,
금통위가 4개보다 적게 읽히면 '뭔가 잘못됐다' 고 보고 아무것도
내보내지 않습니다 (둘 다 연 8회라 그보다 적을 수 없습니다).

## 일정을 직접 넣으려면

`stocks/calendar.json` 을 고칩니다. 깃허브 웹에서 연필 아이콘을
눌러 바로 고칠 수 있습니다.

```json
{
  "일정": [
    { "날짜": "2026-12-10", "갈래": "미국", "이름": "미국 11월 CPI",
      "설명": "한국시간 밤 10시 30분" }
  ]
}
```

- `갈래` 는 `한국` · `미국` · `코인` · `휴장` 중 하나
- 같은 날 같은 이름이 긁어온 것과 겹치면 **여기 적은 쪽이 이깁니다**

## 파일 구조

```
stocks/
├── index.html      화면
├── style.css
├── app.js          JSON 을 읽어 그리기
├── sw.js           인터넷 없이도 열리게
├── manifest.json
├── icons/
├── calendar.json   손으로 적는 일정
├── collect/        일꾼이 쓰는 것 (브라우저에서는 안 돕니다)
│   ├── build.mjs         전부 모아 한 장으로
│   ├── sources.mjs       어디서 가져올지 적은 표
│   ├── rss.mjs           RSS 읽기 (라이브러리 없이 직접)
│   ├── news.mjs          기사 추리기
│   ├── prices.mjs        시세
│   ├── schedule.mjs      계산되는 일정
│   └── calendar-fetch.mjs  FOMC·금통위 긁어오기
└── data/
    ├── latest.json       앱이 읽는 것
    └── 2026-11-05.json   날짜별 보관
```

일꾼은 `.github/workflows/stocks-brief.yml` 에 있습니다.
